# Design references

Reviewed 2026-09-23: [skills.sh](https://www.skills.sh/) (Vercel's skills repository linked homepage), [Vercel agent-skills](https://github.com/vercel-labs/agent-skills), [Superpowers](https://github.com/obra/superpowers), and [gstack](https://github.com/garrytan/gstack).

Adopted an installation-first structure, concise product definition, plain repository navigation, narrow reading column, restrained monospace metadata, and direct links to evidence. The demo is Jevify's own API capture. No copied project logos, star counts, testimonials, or adoption claims. Superpowers and gstack primarily present through repository READMEs; no separate homepage was listed in their GitHub metadata at inspection.
